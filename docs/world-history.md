# 世界同期：1852—1868年多地区研究样本

首页“世界同期”入口打开 `world.html`。本轮按用户选择保持1852—1868年，加入请求的18个地区入口，连同已有中国、日本共20个地区；共19项记录、18处地理参照、26个来源条目。苏联、现代两韩与俄罗斯联邦等后续阶段不在本期时间轴内。

运行 `python3 -m http.server 8000`，访问 `http://localhost:8000/world.html`。沿用原生HTML、CSS、JavaScript和SVG，没有新增浏览器运行时依赖。

## 阅读方式

- 默认“全部地区史事”展示本期材料。地区速览可单选一个入口；多地区筛选支持组合，并显示相关记录数量。
- 点击记录展开条款、人物角色和来源；可添加一项中国相关材料并排对读。对读卡不扩大地图时间或地区筛选，超出条件时会标明其上下文身份。自动计算的日期关系不是因果或传播判断。
- 原三组精读继续独立存在：1858中日对美条约、1868中美迁徙与美国公民资格、魏源与御誓文的求知目的。
- “同日”仅显示确日记录；“同年”还接受已经确定西历年的材料。魏源只署咸丰二年，不能把书目排序年1852当作已核完整西历年界。朝鲜奏报只确定1866年，原农历月日不冒充公历。
- 中俄条约及俄国解放宣言的俄历换算明确保存原值、儒略历、12日差值和西历结果；本期的换算有程序复核，不推广成其他世纪的通用差值。
- 分享链接保存专题、时间、地区、搜索、当前记录和中国对读对象。旧有三组精读链接继续有效。

## 文献与传承

`data/world/history.json`保存来源ID、条款/卷页、短摘与本轮释读、材料传承及未核范围。官方公布本、大学转录、民间转录、出版日记和后编实录分开标明。所有来源仍为`humanReviewed: false`；代理核读不冒充外部历史学者审读。

几个必须保留的区别：

- 女王公告印件署阿拉哈巴德1858年11月1日；英国印度政府法题首日期是8月2日。伦敦点表示立法机关所在城市，不证明女王本人当日的实际位置。
- 北德宪法7月1日取得效力，7月26日公布文书署巴特埃姆斯；不能互换其日期与地点。
- 奥地利侧共同事务法12月21日落款、22日公布，不把整个奥匈妥协压成单日建国。
- 西贡条约包含西班牙这一参与方；蒙古是中俄条约所涉地区，不是独立缔约方。
- Mouhot文本1864年由弟弟按日记、家书整理出版，所记行程为1861年。日记与家书属于同一作者，不能当作两份独立作者见证。
- 《高宗实录》1927年起编、1935年刊毕；本轮读其所收奏报转录。法方理由、战报伤亡等作为各方文书陈述，不作中立裁断。
- 俄国省份清单是白俄罗斯、乌克兰入口的明确依据；受限西部、西南部条例扫描未通读，不加入分地、租役数额。
- 智利批准法现读文字转录，官方咨文另有可读全文；批准、印行和1857年施行分开，未将原刻扫描标作已核。

## 地图来源与聚合

`data/world/land-110m.geojson`为Natural Earth公有领域陆地数据，保留原来固定版本与指纹。它是现代概化陆地参照，不画历史或现代国家疆界，也不表示十九世纪精确岸线。

地点取固定修订的Wikidata、UNGEGN、Marine Regions或UNESCO来源。乌栋使用UNESCO旧都遗址参照，江华是海岛参照；均不表示签署宫殿、军舰锚位或战斗地点的实测坐标。涉及多地区的条约仍按实际文书活动地点定位，不把参与地区自动当作签署地。

缩小视图时，相近地点按屏幕距离聚合；点击聚合标记放大。聚合只改变显示，不改事件坐标、人物或原始记录数量。韩国、朝鲜共享一条半岛史事，不重复计数。

## 维护与验证

修改数据或页面资源后运行：

```sh
node scripts/sync_world_history.cjs
node scripts/validate_world_history.cjs
node scripts/validate_atlas.js --fast
```

版本脚本同时更新CSS、核心逻辑、界面逻辑和数据的内容指纹，避免旧缓存混用。CI仍执行新增校验。校验涵盖请求地区均有真实记录、历史实体、日期精度、半岛去重、明确省份范围、地图聚合、可追溯来源、并排对读和分享状态恢复。

程序检查不能代替版本校勘、原件鉴定、地方执行调查及外部专业审读。独立读者应沿具体链接定位整条或整段，检查释义与比较是否超出材料。
